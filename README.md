# UnJobbed Technologies

A responsive one-page business website built with HTML, CSS and vanilla JavaScript.

## Website sections
- Home and brand introduction
- About UnJobbed Technologies
- Website design and development
- Mobile app design and development
- UI/UX and digital solutions
- Project approach
- Contact details and enquiry form

## Run locally
Download or clone this repository, then open `index.html` in a browser.

## Publish with GitHub Pages
1. Open the repository Settings.
2. Select **Pages** from the left sidebar.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select the `main` branch and `/ (root)`, then save.
5. Wait for GitHub Pages to publish the site. The URL will appear in the Pages settings.
